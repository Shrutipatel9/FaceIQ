# Contract Design — Questions

This stage pins down the formal contracts before building starts. There are three kinds of boundary:

- **Frontend ↔ backend.** The separate Next.js and FastAPI apps talk over HTTP (`NFR-001`, `NFR-005`). This is the main public API, and every unit has endpoints on it.
- **Between backend modules.** The 13 units run inside one backend (modular monolith, units Q2), so modules talk through in-process interfaces. The analysis pipeline also has a step contract.
- **External.** The Stripe webhook is called by Stripe (`FR-015`). Signed-link file downloads are opened directly by the browser.

## Q1 — API versioning and breaking changes

A. All endpoints live under `/api/v1`. The OpenAPI schema generated by FastAPI is the source of truth, and the frontend types are generated from it with a CI drift check. Within v1 only additive changes are allowed, and clients ignore unknown fields. A breaking change needs `/api/v2` alongside v1 until the frontend moves (recommended)
B. No version prefix; the frontend and backend always deploy together

## Q3 — Error response shape

The requirements fix the status codes: 401, 402, 403, 404 for another user's resource, 409 for identity mismatch, 422, and 429.

A. One envelope: `{"error": {"code": "<stable_code>", "message": "<safe text>", "details": {...}, "requestId": "<id>"}}`. Stable codes such as `payment_required` and `identity_mismatch` (with the mismatched angles) are mapped to toast copy on the frontend (recommended)
B. RFC 7807 `application/problem+json`

## Q4 — Contracts between backend modules

A. Each module publishes a typed Python interface: a Protocol class with Pydantic input and output models. These are documented here as shared-schema contracts, covering the key cross-module calls (consent check, identity re-check, paid check, input lock, media store, and the pipeline step contract). Other modules may only import these interfaces, which the import-linter enforces (recommended)
B. Document only the HTTP contracts; module interfaces are decided during the build
